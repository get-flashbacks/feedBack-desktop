Curated plugins install straight from fee[dB]ack — no Git or account needed. The setup wizard walks you through this same catalog. Installing downloads from the network; this catalog itself stays browsable offline.

Installed plugins can be updated, pinned to their current version, downgraded to an earlier one, disabled without losing their files, or uninstalled. Uninstalling keeps a plugin's settings unless you choose otherwise in the confirmation dialog.
